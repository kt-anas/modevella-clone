# Asset Distribution Checklist

The `public/` directory contains demo assets used to demonstrate the template.
This repository does not assert redistribution rights for the photography,
video, logos, or product artwork.

Before selling or redistributing the template:

- Replace the Modevelle demo branding with branding you own or have licensed.
- Replace product photography and social images with licensed assets.
- Remove third-party brand references, including the Nike product demo.
- Confirm the font licenses permit redistribution in a paid template.
- Keep written license records with the release package.

The code and layout can be reused under the project terms, but asset rights must
be verified separately.
